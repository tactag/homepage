PageSmith — quick guide

Quick start

  1. Start with a Template, paste existing text, or build from blocks.
  2. Click any block to select it. New blocks are inserted after the selected block; the block controls change type, move, or delete it.
  3. Use AI Polish to reorganize and rewrite text with style and format options. Hyperlinks are preserved. The Claude API key lives on Railway, not in the page.
  4. Use a Canvas block for freeform layout: drag, resize, rotate, draw, highlight, add shapes, arrows, images, and WordArt-style text.
  5. Paste text keeps hyperlinks and basic bold/italic from Word, email, or the web.
  6. Type directly into the page. Use B/I/Link to format selected text.
  7. Export as HTML, PDF, DOCX, TXT, or Copy for email.

Themes & brand kits

  • Customize… sets colors and font for the Custom theme.
  • Save brand writes a .brand.json (colors, font, logo); Load brand reuses it.

Templates

  • Save current as template… adds it to the menu (★) and downloads a .template.json — the durable copy.
  • Load template file… brings one back. A template captures blocks, theme, brand, logo, and title.

Good to know

  • Run it locally (download, double-click). Clipboard, file-save, and pop-ups may be blocked inside a preview sandbox but function once it’s local.
  • PDF prints from your browser — tick Background graphics so branded bands print.
  • DOCX is editable Word, not a pixel match: rings come in as images, everything else as editable content.
